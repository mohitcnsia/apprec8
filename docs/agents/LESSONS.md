# Lessons for Gemini (printed with every task by next-task.sh; Claude adds one line per real mistake)

1. **Reviews:** a note says what you actually checked ("one answer only: 'an hour' — silent h"), never a template. Unsure → UNSURE. (G15)
2. **QA:** report what the screenshot shows. A blank area, missing text or a face/colour that feels wrong for kids is a FAIL. (G8)
3. **Plausible wrong options:** every wrong option must be a real misconception a kid could believe. No joke options
   ("crystals can run", "turns into metal"). (G16)
4. **Length tell:** the right answer must not be the longest option most of the time; make wrong options just as long and
   specific. `npm test` fails above 40%. (G16: it was 68%)
5. **Facts change:** check that "every year / still / today" facts are still true (Siberian cranes stopped reaching India in 2002). (G16)
6. **Wording:** read each question as a 10-year-old once; fix anything that can be misread ("eyes cut out"). (G16)
7. **Commit everything** you write; never leave files uncommitted; stop after 2 failed tries and report. (G8)
8. **Don't end your turn to report or wait:** the loop dies when you stop. Report by commit; to wait, `sleep 300` and re-check. (G14)
9. **British spelling** (IEO and Indian schools): practise (verb) / practice (noun), colour, cosy, centre. (G17)
10. **Grammar of the question itself:** check tense words in the sentence ("since" needs "have been"); never break grammar to avoid an apostrophe ("teacher table"): rephrase instead. (G17)
11. **Don't overcorrect:** after a fix, re-check the whole set (0% "longest" is as bad as 68%). Keep options short and kid-level. (G16)
12. **Collocation / word-choice questions:** check that no wrong option is ALSO natural English (baking heat, kindled curiosity). (G25)
13. **Spot the error:** exactly one error per sentence, and "No error" must sometimes be the answer. (G25)
14. **No exam labels** in anything kids see (Olympiad / IEO / NSO / IMO). Use "champion level", "challenge". (owner)
