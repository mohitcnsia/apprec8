### B. Pure Visibility Helpers (`utils/courseVisibility.js`)
Created pure, testable helpers:
1. `isTileVisible(tileOrQuest, userDoc, { isAdmin = false, adminUid = ADMIN_UID })`:
   - Public tiles (no `forClassIds` or empty) remain visible to everyone.
   - Restricted tiles (`forClassIds`) are visible only to:
     - Admins / owner (`isAdmin`, `userDoc.isAdmin`, or matching admin UID).
     - Students whose `classIds` contain any of `forClassIds`.
     - Teachers whose `teachesClassIds` contain any of `forClassIds`.
   - Hidden from all other students, unassigned users, and guests.
2. `filterVisibleTiles(tilesOrQuests, userDoc, options)`: Filters an array of tiles or quests using `isTileVisible`.
3. `isEnrolledCourse(tileOrQuest, userDoc)`: Checks if a tile is a course specifically for the student's enrolled class.
4. `orderQuestsForHome(tilesOrQuests, userDoc)`: Moves enrolled course tiles to index `0` (front of carousel) while preserving the original relative order for other tiles.

### C. Screen & Feature Integrations
1. **Home Screen (`screens/home/HomeScreen.js`):**
   - Preserved `forClassIds` in `tileOf(c)`.
   - Filtered `allQuests` with `filterVisibleTiles` and ordered with `orderQuestsForHome`.
   - Students in Class 10-B see Seema's course tile **first** on Home, followed by English Quest. Outside students never see Seema's course tile.
2. **Progress Screen (`screens/progress/ProgressScreen.js`):**
   - Filtered bundled quests with `isTileVisible(m.quest, userData, { isAdmin })`.
   - Course progress and topics only appear for enrolled students, class teachers, and admins.
3. **Parent Week Card (`components/parent/ParentWeekCard.js`):**
   - Filtered `mine` quests using `isTileVisible(m.quest, child)`.
   - Parents only see the course in their weekly summary card if their child belongs to the class.
4. **Teacher Assignments & Progress (`utils/classes.js`):**
   - Updated `questsForTeacher(cls, uid)`:
     - Checks if `cls.id` matches any quest with `forClassIds` for the teacher's subject (`english`).
     - Returns `course-seema-c10-english` alongside base quests for teachers of Class 10-B, allowing Seema to assign topics from this course.
     - Teachers of other classes (e.g. 5-A) do not receive this course.
5. **Admin Seeding (`screens/admin/AdminToolsScreen.js`):**
   - Registered `seemaClass10` in `data/quests/index.js` (`QUESTS` array).
   - `AdminToolsScreen` automatically renders a `SeedTileQuestButton` for Seema's course so it can be seeded directly to Firestore without manual wiring.
