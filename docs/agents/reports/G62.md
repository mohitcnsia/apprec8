## 4. Child Safety & Voice v2 Architecture

### Why Voice (🎤 Say it) is Scheduled for v2
As required by the task:
1. **Sensitive Personal & Biometric Data:** Under the Children's Online Privacy Protection Act (COPPA), India's Digital Personal Data Protection (DPDP) Act, and Google Play Families Policy, a child's raw voice recording is classified as sensitive biometric data.
2. **Prerequisites for v2 Rollout:**
   - **Native Module:** Integration of a local speech-to-text audio library in a subsequent native build (avoiding streaming unencrypted audio to third-party endpoints).
   - **Explicit Parental Consent:** Inclusion of an explicit audio/voice recording toggle in the parent consent gate (Row X).
   - **Privacy Policy Update:** Formal disclosure in the published privacy policy (`docs/policies/privacy.md`) outlining retention, local transcription, and immediate deletion of audio snippets.
3. **v1 Safety Baseline:**
   - Pre-vetted tap options for 100% of children.
   - Optional text box restricted strictly to verified **supervised accounts** where a parent has authorized free-form text input.
   - All typed text is visible **only to the verified owner/admin** in Admin Tools, with zero peer-to-peer social sharing or public display.

## 5. Data Model Specification

```typescript
// 1. Poll Definition Document: polls/{pollId}
interface PollDoc {
  id: string; // e.g. "poll_fun_features_01"
  active: boolean;
  question: string;
  subtitle?: string;
  options: Array<{
    id: string;
    text: string;
    subtitle: string;
    emoji: string;
  }>;
  rewardStars: number; // default 5
  allowText: boolean;  // default true (for supervised accounts)
  minClass?: number;   // e.g. 3
  maxClass?: number;   // e.g. 10
  createdAt: FirebaseFirestore.Timestamp;
}

// 2. Poll Response Document: pollResponses/{responseId}
interface PollResponseDoc {
  pollId: string;
  userId: string;
  userGrade: number;
  userSchoolName?: string;
  selectedOptionIndex: number;
  selectedOptionId: string;
  typedText?: string; // sanitized text from supervised account
  awardedStars: number;
  createdAt: FirebaseFirestore.Timestamp;
}

// 3. User Progress Track: users/{uid}/answeredPolls/{pollId}
// Setting this document suppresses the Home sticky note card once completed.
```
