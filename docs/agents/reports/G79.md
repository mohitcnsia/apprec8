## 2. Detailed Changes by Item

### Item 1: Hide Quests with No Topics for Child's Class
- **Problem:** For classes without main topics in a quest (e.g. Class 10 in Science Quest and Word Power, which only have teaser preview units), empty quest tiles appeared on Home and blank rows (`0/0`) appeared on Progress.
- **Solution:**
  - Added pure helper `questHasTopicsForGrade(nodes, grade)` to `utils/gradeFilter.js`. A quest is visible only if `nodesForGrade(nodes, grade)` contains at least one node with `kind: "main"`.
  - Added safety guard in `nodesForGrade`: returns `[]` when `nodes` is null or empty.
  - Filtered quest grid and `mainQuest` in `screens/home/HomeScreen.js` using `questHasTopicsForGrade`.
  - Guarded the teaser `science-soon` tile so it never renders for classes without science content.
  - Filtered quest rows in `screens/progress/ProgressScreen.js` with `questHasTopicsForGrade`.
  - Unit tests added in `tests/gradeFilter.test.mjs` verifying synthetic trees and all bundled quests (English, Science, Word Power) across Class 4 and Class 10.
- **Device Verification:**
  - For Class 10, Home displays only **English** and **Treasure Words**. Science Quest and Word Power are hidden.
  - On the Progress tab, only active quests with content are shown; Science (0/0) and Word Power (0/0) are hidden.

### Item 2: "Chamku Asks" Frequency & Account Age Guard
- **Problem:** "Chamku asks" idea prompt appeared immediately for brand new accounts and guests.
- **Solution:**
  - Added robust timestamp parser `toEpochMs(val)` in `utils/feedbackPipeline.js` handling Firestore Timestamps (`toMillis`, `toDate`, `seconds`), JS `Date` objects, ISO strings, and epoch numbers.
  - Enhanced `shouldShowWeeklyPrompt` to enforce a 7-day minimum account age (`now - createdMs >= minAccountAgeMs`) in addition to the 7-day interval between prompts.
  - In `components/feedback/HomeIdeaPromptCard.js`:
    - Enforced `authInstance.currentUser` check (`if (!user || !visible) return null`) so guests never see the prompt.
    - Passed `userCreatedAt={userData?.createdAt}` from `HomeScreen.js`.
  - Unit tests in `tests/feedbackPipeline.test.mjs` test day 1, day 6, day 7, day 10, null timestamps, and all Timestamp object variants.

---

### Item 3: Intro vs Map Unit Count Discrepancy
- **Problem:** For Class 10, `EnglishQuestIntroScreen` displayed "Units passed: 0 of 17" while `EnglishQuestMapScreen` displayed "0/16".
- **Root Cause:** `EnglishQuestMapScreen` filtered the quest nodes through `nodesForGrade(nodes, grade)`, whereas `EnglishQuestIntroScreen` was building the tree from raw `nodes` without grade filtering.
- **Solution:**
  - Updated `EnglishQuestIntroScreen.js` to listen to user document `grade`.
  - Filtered nodes through `nodesForGrade(nodes, grade)` prior to `buildQuestPath`.
- **Device Verification:**
  - Both screens now report identical unit totals:
    - English Quest Map: `🏆 1/16`
    - English Quest Intro: `Units passed: 1 of 16 · Steps done: 14`

### Item 4: "Delete My Account" Redesign
