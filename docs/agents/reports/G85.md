## 1. Summary of Deliverables

1. **Dual Android Product Flavors:**
   - **`real` (default):** package `com.mohitchilkoti.apprec8`, app name `apprec8`, adaptive icon background `#3d1141` (purple), googleServicesFile `./google-services.json`.
   - **`preview` (test sandbox):** package `com.mohitchilkoti.apprec8.test` (`applicationIdSuffix ".test"`), app name `Apprec8 TEST`, adaptive icon background `#D97706` (amber), OTA updates channel `preview`, googleServicesFile `./docs/agents/private/google-services.test.json` (and `android/app/src/preview/google-services.json`).
   - *Gradle constraint solved:* Android Gradle Plugin reserves flavor names starting with `test` for test source sets. The flavor is therefore cleanly defined as `preview` (matching the OTA channel and EAS profile), producing package `com.mohitchilkoti.apprec8.test`.

2. **Byte-Identical Real Config Guard:**
   - Evaluated `app.config.js` against origin production baseline.
   - Verified that when building `real` (unset or `APP_VARIANT=real`), the evaluated configuration output is **100% byte-identical** (1,916 bytes) to the production configuration.

3. **JS Runtime Environment Detection (`appVariant`):**
   - Controlled via `APP_VARIANT=test` in `app.config.js`.
   - Configures `extra.appVariant: "test"`.
   - Reads Google web client ID dynamically from `docs/agents/private/google-services.test.json` (`309935610388-vu2pcircoj953jcfjd8aelbmtj5pfua5.apps.googleusercontent.com`).
   - `config/appConfig.js` exports `APP_VARIANT` (`"real"` | `"test"`) and `IS_TEST_VARIANT` (`boolean`).
   - Preserves `ADMIN_UID` and `APPREC8_TEAM_REVIEWER_UID` for full compliance with `tests/releaseConfig.test.mjs`.

4. **Firebase Configuration & Deployments on `apprec8-test`:**
   - Created `.firebaserc` mapping:
     - `"default": "apprec8-ca229"`
     - `"test": "apprec8-test"`
   - Deployed Firestore Security Rules and compound indexes to `apprec8-test` (`firebase deploy --only firestore --project test`).
   - Enabled Google Cloud Service Usage API and Compute Engine API on `apprec8-test` to provision the default compute service account required by 1st Gen Cloud Functions.
   - Deployed **all 31 Cloud Functions** to `apprec8-test` (`firebase deploy --only functions --project test`).

5. **Content Migration Script (`scripts/admin/copyContentToTest.mjs`):**
   - Safe migration script with `--dry` default and `--apply` flag.
   - Copies **content only**:
     - `quests`: 4 documents
     - `quests/{questId}/nodes`: 423 documents
     - `categories`: 27 documents
     - `studyContent`: 250 documents
     - `questions`: 3,393 documents
     - `quest_nodes` (Space legacy): 49 documents
     - `quizzes`: 3 documents
     - **TOTAL: 4,149 documents** safely copied to `apprec8-test`.
   - **Zero User Data Leaked:** Never reads or writes `users`, user progress, children, schools, classes, feedback, reports, or notifications.

6. **Documentation & Clean Test Verification:**
   - Authored full guide in `docs/release/TEST_VS_REAL.md`.
   - **Clean Test Rule Verified:** User sign-up executed with the test project web API key registered immediately in `apprec8-test` Auth, while a lookup in `apprec8-ca229` confirmed `auth/user-not-found`. Throwaway user subsequently deleted.
