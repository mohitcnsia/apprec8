## 1. Feature Implementations

### A. Add a Game from a Link (`utils/chessPgn.js`, `screens/fun/chess/ChessTrainerScreen.js`)
- **URL Resolution (`resolvePgnUrl`):**
  - Lichess single game: `https://lichess.org/<id>` → `https://lichess.org/game/export/<id>`
  - Lichess study chapter: `https://lichess.org/study/<id>/<chapter>` → `https://lichess.org/study/<id>/<chapter>.pgn`
  - Chess.com: Returns a friendly prompt explaining that Chess.com has no open public export API and directs the user to Share → PGN and paste on the Paste tab.
  - Direct PGN links: Accepted directly (e.g. `.pgn` files).
- **Download & Parsing (`fetchPgnFromUrl`, `splitMultiPgn`):**
  - Network error handling with plain-word messages (e.g. "No internet connection or link is unreachable").
  - HTML detection rejects web page HTML when direct file downloads were expected.
  - Multi-game PGN detection: Splits files with multiple games into selectable entries with title, opening, and date.
- **UI Modal:**
  - Tab switcher: `[ From a link | Paste PGN ]`.
  - In "From a link": URL input, informative helper text, activity indicator during fetch.
  - Multi-game picker list rendered if the link contains multiple games, allowing one-tap selection to train immediately.

### B. Board Themes (`components/games/chess/ChessBoard.js`, `screens/fun/chess/ChessTrainerScreen.js`, `screens/fun/chess/ChessPlayScreen.js`)
- Three distinct themes exported via `BOARD_THEMES`:
  - **Wood (Default):** `#F0D9B5` (light) / `#B58863` (dark)
  - **Green:** `#EEEED2` (light) / `#769656` (dark)
  - **Blue:** `#DEE3E6` (light) / `#8CA2AD` (dark)
- Selectable on `ChessTrainerScreen` with live 2×2 mini-swatches and accessible pills.
- Persisted in `AsyncStorage` under key `chessBoardTheme:v1`.
- Passed into `ChessPlayScreen` and `<ChessBoard theme={...} />`.
- High contrast and readable in both light and dark app themes (`quizPalette`).

### C. Watch Mode (`screens/fun/chess/ChessPlayScreen.js`)
- Segmented mode control in header: `[ Guess | Watch ]`.
- **In Watch Mode:**
  - Stepping controls in the thumb zone: `[ ‹ ]` (step back 1 ply), `[ ▶ / ⏸ ]` (slow auto-play at 2.5s intervals), `[ › ]` (step forward 1 ply).
  - Commentary always displayed **above the board** (`bookCard`) showing `game.gameComment` at ply 0 and the master's move notes at ply > 0.
  - Playable side-line variations remain fully interactive.
  - Verdict banners, red/blue/amber arrows, and score calculations are hidden.
  - **Progress Protection:** `AsyncStorage` (`chessProgress:v1`) is strictly isolated and never overwritten while watching. Toggling back to Guess restores the user's active guess state and scores.
