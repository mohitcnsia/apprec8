## 2. Key Pattern Insights

1. **Question Typology:**
   NSO utilizes distinct non-rote formats:
   - Relational Analogies (`Gills : Prawn :: Spiracles : ?`)
   - Multi-statement verification (`(i) and (iii) only`)
   - Venn diagrams and 2-circle/3-circle intersection
   - Flowcharts / Dichotomous keys (branching identification)
   - Experimental setups with controlled variables (e.g. beakers under different conditions)
   - Word anagrams combined with conceptual application
   - Identifying the false statement / finding the odd one out

2. **Achievers Section Calibration:**
   In Class 5, Achievers questions carry **3 marks each** (15 marks out of 60). They always require multi-step reasoning: combining two topics (e.g. animal classification + physiological system) or reading data across 3–4 columns.
