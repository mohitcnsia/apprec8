## 1. System Overview

We designed and built an end-to-end feedback loop that empowers children to share their ideas, comparisons with other apps, and suggestions with the team, while keeping children safe and respecting privacy laws.

```
[ Child in App ] ───► Me tab ("💡 I have an idea!") ──┐
                 ───► Home Feed weekly prompt       ──┼──► Firestore: userFeedback
                 ───► 🚩 Question/Reading Report    ──┤    (existing collection, offline-safe)
                 ───► Chamak Asks Polls             ──┘
                                                              │
                     ┌────────────────────────────────────────┴──────────────────────────┐
                     ▼                                                                   ▼
       [ Owner: In-App Admin Tools ]                                       [ Claude & Owner CLI ]
   Me → Admin tools → "Ideas & reports"                              scripts/admin/feedback.mjs
   • Live feed, newest first                                         • Exports to docs/agents/private/feedback.json
   • Filter: Ideas | Mistakes | Contact | Polls                      • 100% git-ignored (.gitignore)
   • "✓ Done" action toggle                                          • First name & Class only (privacy redacted)
   • Real-time updates                                               • Incremental read guard (reads only new docs)
```

## 2. Children's Experience & Safety

### A. Two Entry Points
1. **On-Demand in Me Tab (`screens/profile/MeScreen.js`):**
   - Added `"💡 I have an idea for Apprec8!"` row under HELP.
   - Tapping opens the interactive `IdeaModal`.
2. **Weekly Proactive Prompt on Home (`components/feedback/HomeIdeaPromptCard.js`):**
   - Sticky card on `HomeScreen` appearing low in the thumb zone.
   - **Frequency guard:** Appears at most **once every 7 days** (`AsyncStorage` key `last_idea_prompt_at`).
   - Dismissible with `✕` (silences for 7 days).
   - Awards **`+5 ⭐`** to the child's stars upon submitting.

### B. Rotating Core Prompts & Tap Choices
3 core prompts designed to elicit actionable comparisons:
1. *"What do you love in another app?"* (🎮 Mini-games & puzzles · 🏆 Badges & outfits · 👥 Playing with friends · 🎵 Sound effects & voice)
2. *"What should we add to Apprec8?"* (📚 Funny stories & pictures · 🔬 Home science experiments · 🧠 Maths riddles · 💎 More Treasure Words)
3. *"What's boring here?"* (😴 Too much text on one page · ⏱️ Quizzes are too long · 🎨 Need more animations · 🌟 Nothing, I love it!)

### C. Child Safety Guard
- Predefined tap choices for 100% of children.
- Free-form text input is restricted **strictly** to accounts where `useCanWriteFreeText()` returns `true` (supervised accounts, remote config `free_text_emails`, or adult accounts).
- Other accounts see `"Something else? Ask a grown-up to tell us."` with zero text input field.

## 3. Owner Experience in Admin Tools

### A. Screen: `screens/admin/IdeasReportsScreen.js`
- Accessible via **Me → Admin tools → "Ideas & reports (feedback, 🚩, polls)"**.
- Restricted to admin (`APPREC8_TEAM_REVIEWER_UID`).
- **Filter Tabs:** `All`, `Ideas 💡`, `Mistakes 🚩`, `Contact 💬`, `Polls 📊`.
- **Card View:**
  - Distinct badge by type.
  - Sender: `First Name · Class N` (e.g. `Pratha · Class 5`).
  - Relative time: `timeAgo` (e.g. `10 min ago`, `Yesterday`).
  - Detailed prompt, choice emoji, question title, and typed text.
  - Interactive **`Mark done` / `✓ Done` toggle** directly updating Firestore `status: "done"`.
- Pull-to-refresh enabled.

### B. Firestore Rules (DR-21)
`userFeedback` already permits `create` from signed-in users. For the owner to read and update `status: "done"` from the app:
```
match /userFeedback/{feedbackId} {
  allow create: if isSignedIn() && request.resource.data.userId == request.auth.uid;
  allow read, update: if isAdmin();
}
```

## 4. Claude CLI & Sync Script

### A. Script: `scripts/admin/feedback.mjs`
- Run via:
  ```bash
  node scripts/admin/feedback.mjs          # Syncs new feedback
  node scripts/admin/feedback.mjs --dry    # Dry-run preview
  node scripts/admin/feedback.mjs --watch  # Background sync every 10 min
  ```
- Uses Firebase Admin SDK (`firebase-admin`) resolving automatically from local or parent worktrees.

### B. Privacy Protection
- Added `docs/agents/private/` to `.gitignore`. **Children's words never reach the public Git repository.**
- Pure redaction function (`redactFeedbackForExport` in `utils/feedbackPipeline.js`):
  - Strips user email, phone number, full name, and raw UID.
  - Retains only: `id`, `type`, `name` (first name), `class`, `prompt`, `choice`, `note`, `status`, and `createdAt`.

### C. Cost Guard (Incremental Sync)
- Maintains sync state in `docs/agents/private/.feedback_sync.json` recording `lastSyncMs`.
- Subsequent runs query **only documents created after `lastSyncMs`**.
