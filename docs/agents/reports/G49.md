## 1. Summary of Changes

Owner feedback: *"earlier anyone could log in and learn right away; now too many taps"*.  
Row Z anchors core actions in the thumb zone with zero unnecessary navigation layers.

### 1.1 Child Home (Z1 — `screens/home/HomeScreen.js`)
- **Thumb Zone Layout:** Generous top breathing room so interactive elements sit naturally near the thumb.
- **Teacher Assignments First:** If a student has assignments, `FROM YOUR TEACHER` card appears on top with assigned topic title, teacher name, due date, and quick `▶` action.
- **Subject Cards List (`YOUR SUBJECTS`):**
  - Sorted by `updatedAt` descending (most recently practised quest always at the top).
  - Each subject row displays:
    - Custom icon badge (English, Science, Word Power, Treasure Words).
    - Subject title.
    - Next step subtitle resolved dynamically via `utils/nextStep.js` (e.g. *"Up next: What is a sentence?"*).
    - Thin progress indicator bar showing completed proportion.
    - Large circular `▶` direct-play button.
  - **Direct Play vs Map:** Tapping the circular `▶` button directly opens the next glowing step (study page in `Apprec8Reader`, quiz in `QuizDetails`, or story in `ReadingScreen`). Tapping anywhere else on the row opens the full Quest Map.
- **Secondary Actions:** "My mistakes" button (if mistakes exist) and compact "Practice paper ›" link at the bottom.

### 1.2 Pure Next-Step Resolver (`utils/nextStep.js` & `tests/nextStep.test.mjs`)
- `findNextStep(nodes, completedKeys)`: Recursively follows `nextSteps` from root to find the glowing node on the Quest Map.
- `getNextStepTitle(nodes, completedKeys, questData)`: Human-readable title for the next step.
- `openNextStep(navigation, questId, stepResult, options)`: Type-safe router directing to the correct screen without opening the map.
- Fully unit tested in `tests/nextStep.test.mjs` (21 test assertions, 100% pass).

### 1.3 Parent Home (Z2 — `screens/home/HomeScreen.js`)
- Card per child ("<name>'s week", Class badge, "updated today").
- 3 key metric stat cards: **Days**, **Minutes**, and **% Right** (in gold).
- "To practise together: <topic> ›" actionable hint.
- Tapping the card navigates directly to the child's detailed weekly view in Progress (`family` view).
- Primary bottom thumb-zone button: **`▶ LET <NAME> PLAY`** (launches `PlayAsChildSheet` / lock mode).

### 1.4 Teacher Home (Z3 — `screens/home/HomeScreen.js`)
- Card per class: Class name, Subject, alert pill for pending approvals ("3 waiting"), total students pill.
- Weekly summary: active students count ("24 of 38 practised"), current assignment topic and due date.
- Reteach recommendation box: highlighted topic where students scored below 60% ("Reported questions (52% right)").
- Tapping the card navigates directly to the class breakdown in Progress (`classes` view).
- Primary bottom thumb-zone button: **`ASSIGN NEXT TOPIC`**.

### 1.5 Auto-routing Progress View (`screens/progress/ProgressScreen.js`)
- Automatically defaults initial tab to `family` for parents, `classes` for teachers, and `me` for students/learners.

### 1.6 Me Tab (Z4 — `screens/profile/MeScreen.js`)
- Content sits low near thumb zone with top breathing room.
- Profile summary header: circular avatar, display name, and role subtitle (*"Teacher · Parent"* or *"Student"*).
- **Row 1:** Green safety row `Need help? Talk to someone` ("Sad, scared or someone is hurting you ›") triggering `HelpSheet`.
- **Primary Rows:** `My class` (quick jump to class or join), `My children` (jump to family progress), `Guides` (interactive walkthroughs).
- **Folded "More" Row:** Single row opening bottom `Sheet` holding everything else:
  - Edit profile
  - Reminders & Messages
  - Join class / Join as teacher
  - Add child / Link existing child account / Set parent PIN
  - Theme switcher, Delete account, Sign out.
- **ADMIN section:** Cleanly retained for the owner (`Decisions`, `Owner extras` toggle, `Admin tools`).
