# G119 Report: G87 Fixes (Teacher Results & Class Summary)

## Summary of Fixes

### 1. Stale Results Fix (`functions/triggers/classSummary.js`)
- **Problem:** `onQuestProgressForClass` previously skipped writes within 5 minutes if `sameLevels(prev.lv, entry.lv)` was true. A student fixing mistakes in My mistakes or completing topics kept their previous status for the teacher for up to 5 minutes.
- **Fix:** Added `sameMap` (for `lv` and `mistakes`) and `sameArray` (for `completed`). Writes are skipped within 5 minutes **only if all three** (`lv`, `mistakes`, and `completed`) are strictly identical. If mistakes change (e.g., student resolves open errors) or new topics are completed, the summary updates immediately.

### 2. Document Size Optimization (`functions/triggers/classSummary.js` & `functions/utils/bundledQuestNodes.js`)
- **Problem:** `completed` was storing individual step keys (`topic__0`, `topic__1`, etc.). For 40 students with hundreds of step keys across multiple quests, document size approached Firestore's 1 MB limit.
- **Fix:** Added `topicDone(node, progressNodes)` evaluation in `functions/triggers/classSummary.js` using lightweight node definitions in `functions/utils/bundledQuestNodes.js`. Only full topic IDs (`id`) that are completely done are stored in `completed`. Unit headers and sub-step keys (`__0`, `__1`) are never stored.
- **Worst-Case Document Size Analysis (40 Students):**
  - Per student per quest:
    - Metadata (`at`, `last`, `week`): ~100 bytes
    - Topic levels (`lv`): ~20 topics × 10 bytes = ~200 bytes
    - Mistakes map (`mistakes`): ~5 branches × 15 bytes = ~75 bytes
    - Completed topics (`completed`): ~25 topic IDs × 12 bytes = ~300 bytes
    - Total per quest: ~675 bytes
  - 2 active quests per student: ~1.35 KB per student
  - 40 students in class: **~54 KB**
  - **Verdict:** ~54 KB is **5.2%** of Firestore's 1,048,576 bytes (1 MB) document limit, safely eliminating document size exhaustion risk.

### 3. Kid's Home Reminder Card (`utils/nudge.js`, `components/home/NudgeCard.js`)
- **Problem:** Reminder nudges landed with `nudge.kind: "remind"`, but `nudgeText` had no case for `"remind"`, falling back to generic practice text without mentioning open mistakes.
- **Fix:** Added `"remind"` handler in `utils/nudge.js` (re-exported from `components/home/NudgeCard.js`):
  - With mistakes: `"<Teacher> reminded you: finish <topic> — <N> mistakes to fix"` (handles singular "1 mistake to fix" and plural "N mistakes to fix").
  - Without mistakes: `"<Teacher> reminded you: finish <topic>"`.
