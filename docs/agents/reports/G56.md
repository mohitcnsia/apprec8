## Executive Summary & Stumbles (Worst First)

| # | Severity | Stumble | Root Cause | Suggested Fix |
|---|---|---|---|---|
| **1** | **BLOCKER** | **First-Run Profile Save Crash (`firestore/permission-denied`)** | In `firestore.rules:61`, rule checks `resource.data.profileLastSavedAt == null`. In Firestore CEL, accessing undefined field on fresh auth user throws a runtime error, triggering permission-denied. Alert says *"You changed your profile a moment ago. Please try again in 10 minutes."* and wipes input fields. | Use `resource.data.get('profileLastSavedAt', null) == null` in `firestore.rules`. Also initialize `profileLastSavedAt: null` in `functions/triggers/auth.js`. |
| **2** | **CRITICAL UX** | **Trapped on "SWITCH TO PARENT" Screen + Misleading Alert** | `ParentPinScreen` has `headerShown: false` and renders no back button in UI. Entering PIN when user is not a child doc triggers callable error: *"Couldn't switch: This isn't a child profile."* User has no exit route without Android system back gesture. | Add a prominent back/cancel button in `ParentPinScreen.js`. Guard `backToParent` call by checking `userData?.isChild`. |
| **3** | **HIGH UX** | **58 Uncategorized Topic Chips Crowd Out 'Who' & ASSIGN Button** | In `AssignPanel` (`TeacherClasses.js`), all elementary topics (Units 0–4) match all grades and render as 58 flat chips. Pushes student selector ("Who"), due date, notes, and ASSIGN button 3–4 screen heights below fold. | Group topic chips by Unit headers (collapsible/segmented) and filter out elementary Units 0–4 when teaching secondary classes (`grade >= 9`). |
| **4** | **MEDIUM** | **Missing Demo School Teacher Invite Code in Admin Tools** | Admin tools has "RESET DEMO SCHOOL" but does not display or generate a teacher invite code for the Demo School. Teacher cannot test "Join as a teacher" flow without database access. | Provide a persistent demo teacher invite code (e.g. `TDEMO1`) with a "Copy code" button on Demo School cards. |
| **5** | **MEDIUM** | **Strict Separation Between Demo School and Real Accounts** | `services/classesApi.js:123` blocks non-demo accounts from joining Demo School classes (*"Demo accounts can only join the Demo School."*). A teacher testing in Demo School cannot test real student enrollment. | Clarify in Seema's teacher guide that Demo School is for previewing pre-populated fake students, and live student enrollment requires a real school class. |
| **6** | **COSMETIC** | **Dangling Empty `code ` Label on Class Card** | In `TeacherClasses.js`, when `joinCode` is null (such as Demo School classes), card subtitle renders: `Demo School (not real) · Class 10 · code ` with trailing whitespace. | Conditionally append join code: `c.joinCode ? ' · code ' + c.joinCode : ''`. |
