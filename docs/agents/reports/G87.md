## 1. Summary of Changes

### Part 1: Done Definition & Assigned Topics Retention
- **Done Rule:** A topic assignment is complete **only** when all steps of that node are completed AND all open mistakes for that topic are cleared (`mistakesLeft === 0`).
- **`utils/assignedTopics.js`:**
  - Added `countTopicMistakes(mistakes, nodeId)` supporting both raw mistakes maps and branch-counted maps from `classSummaries`.
  - Updated `assignedTopics(...)` to retain an assigned topic when `allStepsDone && mistakesLeft > 0`.
  - Added test coverage in `tests/assignedTopics.test.mjs`.

### Part 2: Pure Results Engine (`utils/assignmentResults.js`)
- Created pure function `computeAssignmentResults(assignment, kids, nodesOf, now)`:
  - Groups and sorts students: **Not started** (0) → **Halfway** (1) → **Fixing mistakes (N left)** (2) → **Done ✓** (3).
  - Accuracy: strictly uses the word **Accuracy** (e.g. `Accuracy 85%`), never `"% right"`.
  - Top summary line: `"${done} of ${total} done · ${fixingMistakes} fixing mistakes · ${halfway} halfway · ${notStarted} not started"`.
  - Calculates `canRemind` per student, throttled to max once per day per child.
- Created `computeStarOfTheWeek(kids, now)`:
  - Determines student with best accuracy + effort this week (at least 10 questions answered).
  - Generates WhatsApp share text: `"This week's star: <Name> 🌟"`.
- Created `canRemindStudent(student, now)` and `formatRemindMessage(teacherName, assignmentTitle, mistakesLeft)`.
- Verified in `tests/assignmentResults.test.mjs`.

### Part 3: Teacher Class Screen (`screens/progress/TeacherClasses.js`)
- Updated `AssignPanel`:
  - Renders each assignment as an expandable accordion (auto-expanding the primary assignment).
  - Displays top line summary: `"${done} of ${total} done · ${fixingMistakes} fixing mistakes · ${halfway} halfway · ${notStarted} not started"`.
  - 4-segment visual progress bar (Green: Done, Gold: Fixing mistakes, Blue: Halfway, Gray: Not started).
  - **Star of the Week** card with WhatsApp share action (`Share.share({ message: star.shortShareText })`).
  - **"Remind all not done"** button (disabled if no unreminded students).
  - Student list grouped and sorted:
    - Name
    - Status badge (`Fixing mistakes (N)`, `Halfway`, `Not started`, `Done ✓`)
    - Accuracy badge (`Accuracy XX%`)
    - Per-student **"Remind"** button (shows `"Reminded today"` when throttled).
- In `useEffect`, passes `mistakesMap: d?.mistakes || {}` into `perQuest` so assignment results receive detailed mistake counts.

### Part 4: Kid's Home (`screens/home/HomeScreen.js` & `utils/nextUp.js`)
- In `screens/home/HomeScreen.js`:
  - Passes `mistakesOf` to `assignedTopics`.
  - If `t.allStepsDone && t.mistakesLeft > 0`, displays subtitle: `"Fix N mistakes to finish"`.
  - When tapped, `openTopic` navigates to `EnglishQuestMap` with `{ openMistakes: true }`.
- In `utils/nextUp.js`:
  - Updated `dueText` to return `"Fix N mistakes to finish"` when `t.allStepsDone && t.mistakesLeft > 0`.
  - Verified in `tests/nextUp.test.mjs`.

### Part 5: Server & Cost Guard (`functions/triggers/classSummary.js` & `functions/callable/remindActions.js`)
- In `functions/triggers/classSummary.js`:
  - Extended `entryOf` to store `mistakes` counts by branchId and `completed` steps/nodes so the entire class's assignment and mistake status is available in a single read of `classSummaries/{classId}` (1 doc read instead of 40).
  - Verified in `tests/topicLevels.test.mjs`.
- In `functions/callable/remindActions.js`:
  - Created callable `remindAssignment`:
    - Checks teacher permissions for the class.
    - Daily locking in `assignmentReminders/{classId}_{assignmentId}_{uid}_{date}`.
    - Puts a `nudge` card on the child's Home (`users/{uid}.nudge`).
    - Sends throttled push notification to linked parents (`users/{uid}.parentUids`) via `sendThrottledPushToUser`.
  - Exported in `functions/index.js` and wrapped in `services/assignmentsApi.js`.
  - Tested in `tests/remindAssignment.test.mjs`.
