## 2. In-Depth Component & Architecture Verification

### 2.1 Guide Quests (`utils/guides.js`, `components/guides/GuideStrip.js`, `screens/guides/`)
- **Isolation & Roles:**
  - Children (`isChild: true` or numeric `grade`) are completely isolated from guides: `MeScreen.js:237` suppresses the row, and `guidesFor({ isChild: true })` returns `[]`.
  - Admin sees both "Set up a school" (`admin-school`) and "Start your class" (`teacher-class`).
  - Adults/Teachers see "Start your class" (`teacher-class`).
- **Dynamic State Engine (`utils/guides.js`):**
  - Steps are evaluated purely from system facts read by `loadGuideFacts()` (schools count, classes count, members, teacher assignments).
  - Volatile events (e.g. invite link copied or shared) use local device marks (`f.marks["admin.invite"]`).
  - Idempotent: if a later milestone is reached (e.g. `teachers > 0`), earlier prerequisite steps automatically tick as done.
- **Layout & Positioning:**
  - `GuideStrip` uses absolute layout with safe-area offset: `top: insets.top + 6, left: 12, right: 12`.
  - Folded state collapses width into a compact capsule pill at the top right: `right: 12, borderRadius: 999`.
  - Screen action buttons (`MainButton`) in `SchoolsScreen`, `ClassDetailScreen`, and `InviteTeacherScreen` reside inside `styles.footer` anchored to the screen bottom (`paddingBottom: Math.max(18, insets.bottom + 12)`).
  - Verified: No visual collision or touch intercept between the top guide strip and bottom main action buttons.

### 2.2 Safety & Help Sheet (`components/safety/HelpSheet.js`, `data/helplines.js`)
- **Child Protection Design:**
  - Placement: High prominence on `Me` tab right below the profile badge, easily accessible if a child feels unsafe or distressed.
  - Numbers verified:
    - CHILDLINE: `1098` (Free, 24/7 national child helpline).
    - Tele MANAS: `14416` (National tele-mental health helpline).
    - Emergency: `112` (National unified emergency number).
  - Intent Safety:
    - Utilizes standard `Linking.openURL("tel:<number>")`.
    - Android routes `tel:` schemes without `android.permission.CALL_PHONE` to the system dialer application pre-loaded with the number. The user must manually press the green call button to connect.
    - Accidental dial prevention: 112 omits the Call button entirely, instructing the child to tell an adult.
  - Zero Data Trail:
    - No analytics events (`logEvent`), no Firestore interaction, and no local storage writes. Complete privacy guarantee.

### 2.3 Legacy Content Isolation (`utils/oldContent.js`)
- **Filter Precision:**
  - `FAVOURITES` regex: `/\b(dogs?|puppy|puppies|german shepherds?|animals?|animal kingdom)\b/i`.
  - Uses word boundary matching (`\b`) to prevent false positives (e.g. "Dogmatic" is correctly excluded; "Dog Quiz", "Animal Kingdom", and "German Shepherds" are kept).
  - Owner exemption: `APPREC8_TEAM_REVIEWER_UID` (`ThOziLzf1INR9K9hxZQxOMgjcJD3`) retains full access to all legacy olympiad quizzes and the legacy Space quest map for backward compatibility and maintenance.
  - Tester / Kid accounts: All ugly legacy V1 tiles are suppressed from Home and Fun tabs, creating a clean, modern experience focused on English Quest, Science Quest, and Word Power.

## 4. Emulator Investigation Note
- During emulator cold boot on macOS with API 35, `com.android.bluetooth` crashed repeatedly in `libbluetooth_jni.so` (native stack manager startup), causing `system_server` Watchdog timeouts and heavy host CPU load.
- Disabling the bluetooth service (`pm disable-user --user 0 com.android.bluetooth` and `settings put global bluetooth_on 0`) instantly calmed the emulator from 400% CPU down to 318% idle.
- Emulator was shut down cleanly immediately after verification to maintain zero memory footprint on host Mac.
