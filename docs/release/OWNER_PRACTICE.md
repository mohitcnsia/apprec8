# Master the app first: your private practice (about 55 minutes; updated 2026-11-10)

Just you, before Seema. The Demo School is made up: nothing you do reaches a real person, and nobody sees it.
Do it on your phone. Each part ends with "you can now…".

## 1. See it as everyone else does (10 min)
- [ ] Me → ADMIN → **Owner extras → Off**. Your phone now shows what any grown-up sees.
- [ ] Me → **Guides → Tour of Apprec8**: 6 screens (Home, a quest map, My mistakes, Progress, Need help, children).
  Tap DO STEP, look, tap "Guide ›" to come back.
- You can now explain: quests, Learn cards, practice, Boss, My mistakes, Progress, Need help.

## 2. Be a child (10 min)
- [ ] Me → My children → your test child ("Test", Class 10) → **Play as** → no timer.
- [ ] Home → a quest → the glowing circle → Learn cards → answer 8 questions. Get 2 wrong on purpose.
- [ ] On a wrong answer, tap **"Why not this option?"**: why each wrong option is wrong (Grammar Pro explanations still being filled).
- [ ] Home → **My mistakes** → fix them. Progress → see your stars and streak.
- [ ] Class 10 child: Home → Explore → **Check-up** → answer a few, Submit → **Accuracy by topic**, weakest first →
  **Practise this ›** opens that topic. The next check-up has different questions.
- [ ] Me → **Switch to parent (PIN)**.
- You can now show a child how to learn, fix mistakes and see their stars.

## 3. Be a parent (10 min)
- [ ] Me → Sign out → **Use email instead** → `demo.parent@example.com` + the demo password (in Play Console).
- [ ] Progress → **My children** → the child's week: days, minutes, strong topics, one thing to do at home.
- [ ] Me → My children → **Link my child's own account** → see the 6-number code and **SHARE CODE**.
- [ ] Why it matters: a child can't join a class until a parent is linked (Seema's rule). Without one, Join a class says
  "Ask your parent to add you"; with one, the child just taps JOIN.
- You can now explain to a parent: add a child, link a child's own phone, read the week, why the class needs them.

## 4. Be a teacher (10 min)
- [ ] Sign out → `demo.teacher@example.com` + the demo password.
- [ ] Home: **Needs you** at the top when a kid waits (tap → approve), then the class card.
- [ ] Progress → **My classes** → a class: Waiting for you (approve), each student's week, weak topics,
  **Check-up by topic** (class Accuracy per topic, names under 60%).
- [ ] **Assign a topic** with a due date. Look at **SHARE CODE**.
- [ ] Me → Guides → **For teachers: start here** (Seema's one-pager).
- You can now walk Seema through her 4 jobs.

## 5. Pilot controls (5 min, your real account)
- [ ] Sign out → your own Google account.
- [ ] Me → Admin tools → Schools & classes → 10-A: **"Pilot: open all levels for these kids"**. Look, don't tap: it
  changes Seema's real class. You tap it on pilot day (15 Nov).
- [ ] Me → **Decisions**: answer Claude's questions with one tap. Me → **Tell us**: send a note to Claude.
- You can now run the pilot: open the levels, approve, answer Claude.

## 6. Back to you (2 min)
- [ ] Me → ADMIN → **Owner extras → On**.
- [ ] Write down anything that confused you: Me → Decisions → "What confused you most?", or tell Claude.

Then: the dry run with Seema (Seema's pilot tab), where you lead and she follows.
